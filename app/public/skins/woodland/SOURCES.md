# Woodland skin assets

| File | Asset | Author | Licence |
| --- | --- | --- | --- |
| galmuri*.woff2 | Galmuri 2.40.3 (11 Regular and Bold) | Lee Minseo (quiple) | SIL Open Font License 1.1 (see GALMURI-OFL.txt) |
| icons/*.svg | Pixel weather icons | original (this repo) | same licence as the repo |
| frame*.png, wood*.png, vines-*.png, *-clouds.png, night-stars*.png | Generated by skins/woodland-art.mjs | original (this repo) | same licence as the repo |
| day.png, night.png | Forest-and-lake scenes generated with the built-in imagegen tool from the supplied concept; see SCENE-PROMPTS.md | AI-generated for this repo | same licence as the repo |

`npm run art` regenerates the frames and transparent sky layers; it preserves the illustrated day/night scenes. Clouds drift independently, with a static lake and reduced-motion support.

Font source: https://github.com/quiple/galmuri · https://cdn.jsdelivr.net/npm/galmuri@2.40.3/dist/
